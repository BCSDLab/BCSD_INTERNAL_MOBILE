# BCSD INTERNAL MOBILE

![Image](docs/img/bcsd_logo.png)

BCSD INTERNAL은 BCSD 동아리 회원 관리 및 모집을 위해 개발된 프로젝트입니다.

## 개발 환경

- Android Studio Narwhal | 2025.1.1
- Gradle 8.14.2
- AGP 8.11.0
- Kotlin 2.2.0

## 기술 스택

- Compose multiplatform
- Ktor
- Koin
- Orbit MVI
